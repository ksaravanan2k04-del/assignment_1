# assignment_1

Building a project from real-life experiences always makes the journey more relatable."
​For this expense-sharing project, I used real data from a recent trip I took with my friends. Having a real-life scenario made it much easier for me to connect with the logic and understand the problem statement.
​However, the process wasn't without its struggles. I ran into quite a few roadblocks along the way:


​Logic Errors: Early on, I mixed up the calculation signs—using -= instead of += for the participated expenses and vice versa for the payer's share. It completely threw off my final output, and it took some patient debugging to spot and fix those small mistakes.


​Environment Issues: Google Colab wasn't cooperating with my workflow, which slowed me down. Switching to Visual Studio Code turned out to be a game-changer, making it much smoother to build and test the project.

​First-Time GitHub Struggles: Since this was my first time uploading a project to GitHub, I was initially confused about how to structure and push the files properly. Watching a few YouTube tutorials helped me figure it out step-by-step.

​Looking back, fixing each mistake one by one taught me way more than getting it right on the first try. Really happy to finally wrap this up!
